1. **Aucun pseudo-programme agrégé** : Les 10 programmes officiels sont strictement individualisés selon la nomenclature canonique DGBF.
2. **UNKNOWN ≠ 0** : Les valeurs absentes restent `null`.
3. **Zéro fictif interdit** : Seuls les vrais zéros documentés sont conservés.
4. **Pas de concepts communaux** : Zéro Budget Primitif, zéro CA municipal, zéro DGF/DGE sur la fiche ministérielle.
5. **Vérifiabilité directe** : Chaque URL correspond à une ressource DGBF accessible.
