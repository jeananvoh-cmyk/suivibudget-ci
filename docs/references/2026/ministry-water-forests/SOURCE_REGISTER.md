## 5. Doctrine d'Intégrité Républicaine

1. **Compte Spécial / FFN (23228)** : Le Fonds Forestier National est un compte d'affectation spéciale représenté sous son code de programme officiel 23228, avec 3 actions clairement séparées.
2. **UNKNOWN ≠ 0** : Règle absolue respectée.
3. **Zéro double comptage** : Les crédits du FFN ne sont ni ajoutés ni soustraits artificiellement du budget total.
4. **Vérifiabilité directe** : Chaque chiffre est rattaché à son tableau officiel du DPPD-PAP.
