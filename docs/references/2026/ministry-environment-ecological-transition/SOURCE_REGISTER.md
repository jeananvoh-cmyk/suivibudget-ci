1. **Exactitude des codes d'actions** : L'action 2107904 n'existant pas dans la nomenclature officielle DGBF 2026 (le ministère sautant directement à 2107905), aucun code artificiel n'a été inséré.
2. **UNKNOWN ≠ 0** : Règle absolue respectée.
3. **Réconciliation totale** : Somme des actions = Dotation du programme, et Somme des programmes = Dotation ministérielle.
4. **Vérifiabilité directe** : Chaque chiffre est rattaché à son tableau officiel du DPPD-PAP.
